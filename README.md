-> Madhav Kawatra — Portfolio

A quiet, editorial personal portfolio. Plain HTML, CSS and vanilla JavaScript — no build step, no dependencies (only the DM Sans font from Google Fonts).

```
portfolio/
  index.html        all content and structure
  css/style.css     design (colours are variables at the top)
  js/script.js      active nav, lightbox, scroll reveal
  assets/
    photography/    your photos as .jpg + .webp
    projects/       project screenshots 
    design_references/  reference screenshots 
```
